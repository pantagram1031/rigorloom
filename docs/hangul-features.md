# 한글 기능과 Rigorloom

Rigorloom이 한글(.hwpx) 문서에서 할 수 있는 편집을 한글 메뉴 기능별로 적은 표입니다.

- **지원**: Rigorloom 문서 동작(`rigorloom edit`, MCP `edit` 도구)이 있고, 그 동작을 실제 엔진에 돌려 결과를 확인하는 테스트가 있습니다.
- **부분**: 동작은 있지만 결과를 확인하는 테스트가 아직 없거나, 기능의 일부만 다룹니다.
- **미지원**: 아직 동작이 없습니다. 문서에 이미 들어 있는 그 부분은 Rigorloom이 고치지 않습니다.

동작의 키와 값은 [doc-core.md](doc-core.md)에 있습니다. 맞춤법 검사는 이 표의 범위가 아닙니다. 이 표는 기능이 늘 때마다 함께 고칩니다.

| 한글 기능 | Rigorloom | 동작 |
|---|---|---|
| 글자 모양 (글꼴, 크기, 장평, 자간, 진하게, 기울임, 밑줄, 취소선, 색, 음영, 위·아래첨자) | 지원 | `char_shape` |
| 형광펜 | 지원 | `char_shape` |
| 글자 모양 기타 (외곽선, 그림자, 양각·음각, 강조점, 글자 테두리) | 부분 | `char_shape`, `style.create` (외곽선·그림자·양각·음각·강조점·글자 테두리/단색 배경; 변마다 다른 글자 테두리와 무늬·그러데이션 배경은 없음) |
| 문단 모양 (정렬, 여백, 들여쓰기·내어쓰기, 줄 간격, 문단 위·아래) | 지원 | `para_shape` |
| 문단 모양: 줄 나눔·쪽 나눔 설정 (다음 문단과 함께, 문단 보호, 외톨이줄, 앞에서 쪽 나눔) | 부분 | `para_shape` |
| 탭 | 부분 | `para_shape`, `style.create` (탭 위치·종류·채울 모양과 자동 탭; 구역 기본 탭 간격 변경은 없음) |
| 문단 테두리/배경 | 부분 | `para_shape`, `style.create` (네 변 공통 테두리·단색 배경·간격·연결만, 변마다 다른 테두리·무늬/그러데이션 배경·여백 무시는 없음) |
| 개요 번호 (개요 1-7) | 지원 | `numbering` |
| 문단 번호·글머리표 (수준 1-7, 시작 번호, 새 번호) | 지원 | `numbering` |
| 스타일 적용 | 지원 | `style` |
| 스타일 만들기·고치기 | 부분 | `style.create` (만들기만, 고치기·지우기는 없음) |
| 표 만들기 | 지원 | `insert_table` |
| 표 셀 입력, 줄 추가·삭제 | 지원 | `table.set_cells`, `table.add_row`, `table.delete_row` |
| 셀 합치기·나누기 | 지원 | `table.merge`, `table.split` (한 번의 편집에서 표마다 표 구조 동작 하나) |
| 칸 추가·삭제, 너비·높이 | 지원 | `table.add_col`, `table.delete_col`, `table.size` (한 번의 편집에서 표마다 표 구조 동작 하나, 셀 너비·높이 같게는 없음) |
| 표 테두리·배경 | 부분 | `table.cell_style` (단색 배경만, 무늬·그러데이션 배경과 대각선은 없음) |
| 셀 정렬·안 여백 | 지원 | `table.cell_style` |
| 제목 줄 반복, 쪽 나눔 | 지원 | `table.style`, `table.cell_style` |
| 캡션 | 부분 | `caption` (표에 캡션 넣기만, 이미 캡션이 있는 표와 캡션 고치기·지우기는 없음) |
| 표 계산식 | 부분 | `table.formula` (블록 합계·평균·곱과 계산식 넣기만; 계산식 고치기·지우기, 쉬운 계산식 등은 없음) |
| 편집 용지 (용지, 방향, 여백, 제본) | 지원 | `page_setup` |
| 구역 나누기 | 부분 | `break` (마지막 구역에서만, 구역 첫 문단 제외) |
| 머리말·꼬리말 (양쪽, 홀수·짝수 쪽) | 지원 | `header` (글자만, 문서에 머리말 스타일이 있어야 함) |
| 머리말·꼬리말 안의 쪽 번호·표·그림 | 부분 | `header` (`{page}`·`{pages}`로 쪽 번호·전체 쪽수만, 표·그림 없음) |
| 쪽 번호 매기기 (위치, 번호 모양, 줄표) | 지원 | `page_number` |
| 시작 쪽 번호, 새 번호로 시작 | 부분 | `page_setup` (`start_page`), `new_number` (쪽·각주·미주·그림·표·수식 새 번호 넣기만, 고치기·지우기는 없음) |
| 감추기 | 부분 | `hide` (머리말·꼬리말·쪽 번호·테두리·배경·바탕쪽 감추기 넣기만, 이미 감추기가 있는 문단과 고치기·지우기는 없음) |
| 쪽 테두리·배경 | 부분 | `page_setup` (`border`: 네 변 공통 테두리·단색 배경(선 없는 배경 포함)·간격·적용 쪽·기준 위치·머리말/꼬리말 포함; 변마다 다른 테두리와 무늬·그러데이션·그림 배경, 채울 영역 선택은 없음) |
| 다단 (단 수, 간격, 구분선, 단 나누기) | 지원 | `columns`, `break` |
| 다단 설정 나누기, 단 너비 따로 | 부분 | `columns` (`split`, `widths_mm`, `gaps_mm`; 구역 첫 문단과 이미 다단 정의가 있는 문단에서는 나누기 제외, 나눈 다단 정의 지우기는 없음) |
| 쪽 나누기 | 지원 | `break` |
| 각주·미주 | 부분 | `note` (넣기만, 각주·미주 고치기·지우기는 없음) |
| 그림 넣기 | 지원 | `insert_picture` |
| 그림 크기·위치·배치(어울림) | 부분 | `insert_picture`, `picture` (크기·글자처럼 취급·배치·기준과 위치만, 회전·자르기·효과 없음) |
| 그림 자르기·효과 | 미지원 |  |
